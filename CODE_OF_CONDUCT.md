# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for
everyone, regardless of background or identity.

## Standards

Examples of behavior that helps: being respectful of differing viewpoints,
giving and gracefully accepting constructive feedback, and focusing on what is
best for the project and its users.

Examples of unacceptable behavior: harassment, insulting or derogatory
comments, personal or political attacks, and publishing others' private
information without permission.

## Scope

This applies in all project spaces — issues, pull requests, and discussions —
and when representing the project in public spaces.

## Enforcement

Report unacceptable behavior to the maintainer via the project Discord
(<DISCORD_INVITE>) or the contact on their GitHub profile. Maintainers may
remove, edit, or reject contributions that
violate this Code of Conduct, and may ban temporarily or permanently any
contributor for behaviors they deem inappropriate.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
