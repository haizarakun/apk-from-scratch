# FAQ・トラブルシューティング

## インストールできない・起動しない

**「アプリはインストールされていません」「解析エラー」**
- Android 11 以上で稀に出る場合、`--target-sdk 30` 以上を試してください。
- ダウンロード時に壊れていることがあります。`apkinspect app.apk` で読めるか確認。

**「署名が一致しません / 既存のパッケージと競合」**
- 前回と違う鍵で作った更新版です。同じ `--key`（ブラウザなら Secret `APK_SIGNING_KEY`）を
  使うか、旧版を一度アンインストール。

**「提供元不明のアプリ」と出る**
- ストア外アプリを入れるときの通常の確認です。許可して進めてください。

**Play プロテクトに止められる**
- 「詳細 → インストール」で続行できます。自己署名のため、初回は警告が出ることがあります。

**インストール直後に落ちる**
- Web アプリで `index.html` が無い → `--web` のフォルダ直下に `index.html` を置く。
- JSON の `set_text`/`fetch` の `target` が画像を指している → 文字かボタンの `id` に。

## 動作

**通信（fetch）が「エラー」になる**
- `http://` は不可。`https://` のみ。
- 相手サーバーが CORS を許可していない場合、Web アプリでは失敗することがあります
  （JSON 設計図の `fetch` はネイティブ通信なので CORS の影響を受けません）。

**カメラ／現在地が動かない**
- `--permissions camera`（`location`）を付けたか確認。起動時の許可ダイアログで「許可」。
- 一度「拒否」した場合は、端末の設定 → アプリ → 権限で有効に。

**通知が出ない**
- Android 13 以上では端末設定でアプリの通知が OFF のことがあります。設定で ON に。
- Android 8.0 未満はトースト表示になります。

**`alert()` が小さく出るだけ**
- 仕様です（トーストとして表示）。ダイアログが欲しければ HTML でモーダルを作ってください。

**戻るボタンでアプリが閉じる**
- Web の履歴が無いときは閉じます。ページ遷移していれば履歴を戻ります。

**画像が表示されない（JSON）**
- `src` は JSON ファイルからの相対パス。`src_url` は `https://` のみ、5 MB まで。

## できないこと（正直に）

| できない | 代わりに |
|---|---|
| プッシュ通知（サーバーから送る） | アプリ内からの通知 `App.notify`。定期取得は Web アプリで `setInterval`＋`fetch` |
| Bluetooth / NFC / USB | 未対応 |
| バックグラウンド常駐・アラーム起動 | 未対応（アプリを開いている間だけ動く） |
| ウィジェット・ライブ壁紙・Wear | 未対応 |
| ネイティブ（C/C++）ライブラリ | 未対応 |
| Google Play 公開用の AAB | 未対応（APK のみ。直接配布・Termux・F-Droid 系向け） |
| 難読化・圧縮 | 未対応（学習用途では読める方が良いため） |

これらは「Android Studio が必要な領域」として残しています。

## そのほか

**アプリのサイズは？** 数 KB〜数十 KB（Web アプリはあなたの HTML/画像の分だけ増えます）。

**自作アプリを配布していい？** はい。MIT ライセンスで、生成物の権利はあなたのものです。

**鍵を失くした** 新しい鍵で作った版は旧版の上に入りません。ユーザーには一度アンインストール
してもらう必要があります。鍵は必ずバックアップを。
