# いちばん簡単な使い方（コマンド不要・ブラウザだけ）

プログラミングやコマンド入力は要りません。GitHub のページ上でボックスを埋めて
ボタンを押すだけで、あなたのアプリ（.apk）ができます。

## 用意するもの

- GitHub のアカウント（無料。持っていなければ github.com で登録）
- スマホ、または PC のブラウザ

## 手順

1. このリポジトリを自分のものにコピーします（**Fork**）。
   ページ右上の **Fork** ボタン → **Create fork** を押すだけ。
   （自分のアカウント上でボタン実行を有効にするために必要です）

2. コピーした自分のリポジトリで、上のタブの **Actions** を開きます。
   初回は「I understand my workflows, go ahead and enable them」を押して有効化。

3. 左の一覧から **「Make an APK (no coding)」** を選びます。

4. 右側の **Run workflow** を押すと、入力フォームが開きます。次の4つを埋めます。

   - **App id**: アプリの識別子。他と重複しない逆ドメイン形式。例 `com.yourname.hello`
   - **App name**: ホーム画面のアイコン下に出る名前。例 `わたしのアプリ`
   - **Text the app shows**: アプリを開いたとき画面に出る文字。例 `こんにちは！`
   - **Icon color**: アイコンの色。6桁の16進数。例 `1E88E5`（青）、`E53935`（赤）、`43A047`（緑）

5. もう一度 **Run workflow** を押すと、ビルドが始まります（1〜2分）。

6. 実行が緑のチェックになったら、その実行ページを開き、下の
   **Artifacts** にある **apk** をクリックしてダウンロード。
   （`apk.zip` がダウンロードされるので、解凍すると `app.apk` が出てきます）

## スマホに入れる

Android スマホに `app.apk` をコピーして、ファイルアプリから開きます。
「提供元不明のアプリ」の許可を求められたら、許可してください。
（これはあなた自身が作ったアプリなので安全です。ストア外アプリを入れるとき
Android が毎回出す確認です）

開くと、5 で入れた文字が画面に表示される小さなアプリが立ち上がります。

## うまくいかないとき

- **Actions にワークフローが出ない** → Fork したか、Actions を有効化したか確認。
- **赤い×で失敗する** → App id が `com.` で始まる形式か、Icon color が6桁の
  16進数（0-9 と A-F だけ）か確認して、もう一度 Run workflow。
- それでも分からなければ、[サポート](../SUPPORT.md)（Discord）で気軽に聞いてください。
  個人の方のサポートまで対応しています。
