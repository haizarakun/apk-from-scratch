# サポート / Support

## 日本語（メイン）

サポートの窓口は **Discord** です。質問・使い方・不具合の相談はこちらへ。

- Discord: <DISCORD_INVITE>

まず [README](README.md) と [docs/format.md](docs/format.md)、各
[`examples/`](examples/) を見てから、解決しなければ Discord で聞いてください。

不具合として GitHub Issue を立てる場合は、実行したコマンド・出力・（端末に
インストールした場合は）Android のバージョンを添えてください。最小再現スクリプトが
あると最も助かります。

セキュリティに関わる報告だけは公開 Issue を避け、[SECURITY.md](SECURITY.md) の
非公開ルートでお願いします。

## English (partial)

Support is provided mainly in Japanese. The main channel is **Discord**
(<DISCORD_INVITE>). English questions are welcome there and answered on a
best-effort basis. Other languages are not supported.

For security issues, do not open a public issue — see [SECURITY.md](SECURITY.md).
